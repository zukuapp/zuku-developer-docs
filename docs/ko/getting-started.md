# 시작하기

이 가이드에서는 ZukuJS CLI로 새 게임 프로젝트를 만들고, 브라우저에서 실행한 뒤, 검사하고 ZWF 패키지로 묶습니다. 모든 단계는 로컬에서 동작하며 로그인이 필요하지 않습니다.

## 준비

[설치](installation.md)를 마치고 버전이 표시되는지 확인합니다.

```sh
zuku --version
```

`zuku` 대신 `zukujs`를 써도 똑같이 동작합니다.

## 1. 프로젝트 만들기

```sh
# 현재 위치에 my-game 디렉터리를 새로 만듭니다
zuku create my-game
cd my-game
```

이름에는 영문 소문자, 숫자, `_`, `-`만 쓸 수 있고 최대 64자입니다. 같은 이름의 경로가 이미 있으면 덮어쓰지 않고 오류를 표시합니다. `create`는 이름만 받으며 템플릿 선택 옵션은 없습니다.

생성되는 파일은 다음과 같습니다.

| 파일 | 역할 |
| --- | --- |
| `zukujs.json` | 프로젝트 매니페스트(이름, 버전 `0.1.0`, 패키지 형식 `zwf` 등) |
| `src/index.html` | 게임 진입점 |
| `src/game.js` | 게임 코드 |
| `README.md` | 프로젝트 안내 |
| `.gitignore` | 출력물 제외 설정 |

만들어지는 게임은 Canvas로 그린 점프 장애물 러너입니다. 스페이스바, 위쪽 화살표, 화면 탭으로 점프해 장애물을 피합니다. 빌드 단계나 외부 의존성이 없습니다.

## 2. 로컬에서 실행하기

프로젝트 디렉터리 안에서 실행합니다.

```sh
# 현재 디렉터리의 게임을 로컬 미리보기로 띄웁니다
zuku run
```

`run`은 현재 디렉터리를 대상으로 하며 경로 인수를 받지 않습니다(`zuku run .`은 인수 오류가 됩니다). 실행하면 터미널에 `게임 미리보기:`와 함께 `127.0.0.1` 주소가 표시됩니다. 이 주소를 브라우저에서 열어 게임을 해 보세요. 종료하려면 `Ctrl+C`를 누릅니다.

```sh
# 포트를 직접 지정할 수도 있습니다
zuku run --port 5173
```

## 3. 코드 고치기

`src/game.js`를 열어 속도나 점프 높이 같은 값을 바꿔 보세요. 미리보기는 실행 시점의 스냅샷이므로, 고친 내용을 보려면 `Ctrl+C`로 종료한 뒤 `zuku run`을 다시 실행합니다.

## 4. 검사하기

```sh
# 매니페스트와 소스 파일을 패키지 규칙으로 검사합니다
zuku validate .
```

`validate`는 게임 코드를 실행하지 않고 파일 구성과 매니페스트만 확인합니다. 문제가 있으면 오류 코드와 메시지를 표시하고 0이 아닌 종료 코드로 끝납니다. 코드의 의미는 [오류](errors.md)를 참고하세요.

## 5. 패키지 만들기

```sh
# dist/my-game-0.1.0.zwf 파일을 만듭니다
zuku package . --format zwf
```

패키지에는 `src/` 안의 파일만 들어갑니다. 같은 입력에서는 항상 같은 바이트의 파일이 만들어집니다. 이미 출력 파일이 있으면 덮어쓰지 않으므로, 다시 만들려면 `--force`를 붙이세요. ZIP이 필요하면 `--format zip`을 사용합니다.

만든 패키지도 검사할 수 있습니다.

```sh
zuku validate dist/my-game-0.1.0.zwf
```

## 스크립트에서 사용하기

명령에 `--json`을 붙이면 결과를 한 줄 JSON으로 출력합니다. 성공은 stdout, 실패는 stderr로 나옵니다.

```sh
zuku validate . --json
```

## AI로 게임 만들기

CLI 게임 에이전트는 선택한 외부 AI 제공자의 자격 증명이나 로컬 모델로 실행할 수 있습니다. ZUKU AI와 초안 업로드·게시에는 ZUKU 계정이 필요합니다. [CLI 인증](cli/authentication.md), [제공자](cli/providers.md), [게임 에이전트](cli/agent.md)를 확인하세요. 호스팅 웹 AI와 앱 내 AI는 준비 중이며 개시 일정은 미정입니다. Android 앱 자체는 [APK 미리보기](https://apk.zuzunza.com/)에서 받을 수 있습니다.
