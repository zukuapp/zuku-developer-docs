# 스타터

ZUKU 게임은 어디서 시작하든 같은 길을 거칩니다. 로컬에서 만들고, 브라우저로 확인하고, 검사한 뒤 `.zwf` 패키지로 묶습니다. 이 섹션에서는 세 가지 시작점을 소개합니다. 지금 상황에 가장 가까운 것을 고르면 됩니다.

아직 CLI를 설치하지 않았다면 [설치](../installation.md)와 [시작하기](../getting-started.md)를 먼저 보세요. `zuku`와 `zukujs`는 같은 명령이며, 이 문서에서는 `zuku`로 표기합니다.

## 한눈에 비교

| | [Canvas 러너](html5.md) | [Phaser 2D](phaser.md) | [기존 게임 이전](existing-game.md) |
| --- | --- | --- | --- |
| 시작 방법 | `zuku create <name>` 또는 압축 파일 | 압축 파일 내려받기 | 내 프로젝트에 매니페스트 추가 |
| 엔진 | 순수 Canvas 2D | 프로젝트에 포함된 Phaser | 기존 코드 그대로 |
| 외부 의존성 | 없음 | 없음(CDN·npm 불필요) | 상대 경로 파일로 정리 필요 |
| 빌드 단계 | 없음 | 없음 | 미리 빌드한 결과물 사용 |
| 잘 맞는 경우 | 처음 만드는 게임, 짧은 아케이드 | 스프라이트·물리·씬이 필요한 2D 게임 | 이미 동작하는 HTML5 게임 |

## 어떤 것을 고를까요

- **ZUKU가 처음이라면** [Canvas 러너](html5.md)로 시작하세요. 명령 한 줄로 바로 플레이할 수 있는 점프 장애물 게임이 만들어지고, 파일도 두 개뿐이라 전체 흐름을 익히기 좋습니다.
- **씬 관리, 스프라이트 애니메이션, 물리 엔진이 필요하다면** [Phaser 2D](phaser.md) 스타터를 내려받으세요. Phaser 파일이 프로젝트 안에 함께 들어 있어 네트워크 없이도 실행됩니다.
- **이미 만든 게임이 있다면** [기존 게임 이전](existing-game.md) 가이드를 따라 매니페스트를 추가하고 경로와 입력을 점검하세요.

## 공통 작업 흐름

어떤 스타터를 고르든 프로젝트 폴더 안에서 아래 순서로 진행합니다.

```sh
# 1. 프로젝트 폴더로 이동
cd my-game

# 2. 로컬 미리보기 (Ctrl+C로 종료)
zuku run

# 3. 매니페스트와 소스 파일 검사
zuku validate .

# 4. 배포용 패키지 생성 (기본 출력: dist/<name>-<version>.zwf)
zuku package . --format zwf
```

1. **미리보기** `zuku run`은 현재 폴더의 게임을 `127.0.0.1`에서 띄우고 주소를 알려 줍니다.
2. **검사** `zuku validate .`는 게임 코드를 실행하지 않고 매니페스트와 파일 규칙만 확인합니다.
3. **패키지** `zuku package`는 같은 입력에서 항상 같은 바이트를 만드는 재현 가능한 `.zwf` 파일을 만듭니다.
4. **게시** 패키지를 올리고 공개하는 방법은 [게시](../cli/publishing.md)에서 다룹니다.

명령별 옵션은 [명령 참조](../cli/commands.md)에, 오류 코드는 [오류](../errors.md)에 정리되어 있습니다.

## AI 에이전트로 시작하기

직접 코드를 쓰는 대신 한 줄 요청으로 게임을 만들 수도 있습니다. [게임 개발 에이전트](../cli/agent.md)는 설계부터 구현, 실제 브라우저 플레이테스트, 패키징까지 로컬에서 진행하며 Canvas 기반 게임과 Phaser 기반 게임을 모두 만들 수 있습니다.

```sh
# 요청 한 줄로 로컬 게임 생성 (기본값은 게시하지 않음)
zuku agent "세 갈래 길에서 떨어지는 블록을 피하는 아케이드 게임"
```

에이전트를 쓰려면 먼저 [로그인](../cli/authentication.md)하고 모델 [제공자](../cli/providers.md)를 설정해야 합니다. 사용할 모델은 [모델](../cli/models.md) 문서를 참고하세요. 에이전트가 만든 프로젝트도 결국 위와 같은 매니페스트 구조를 가지므로, 생성 후에는 이 섹션의 스타터 문서를 그대로 참고해 다듬을 수 있습니다.
